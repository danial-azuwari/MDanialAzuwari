HR & PAYROLL AUTOMATION

Mini HRIS System

Spreadsheet-Based Human Resource Information System — a simulation built to centralize employee data and automate repetitive HR administrative processes.

Overview

Mini HRIS System is a spreadsheet-based Human Resource Information System simulation designed to centralize employee data and automate repetitive HR administrative processes. The system connects employee registration, attendance, overtime, payroll, monitoring, and document generation into one structured workflow using Google Workspace.

The Problem

HR administration often involves repetitive data entry, manual calculations, and separate records for employee information, attendance, overtime, and payroll. These processes can take time and increase the risk of inconsistent or incorrect data. This project was created to turn those disconnected manual processes into a more structured and automated workflow.

What I Built / My Role

I designed and built a lightweight HRIS workflow that connects data collection, data processing, HR calculations, and automated outputs. As the System Designer & Developer, I designed the data structure, built the Google Forms and Google Sheets workflow, created the spreadsheet-based calculation logic, and developed the dashboard and automated document generation. The system was designed to handle employee data, attendance, overtime, payroll, and employee documents within one connected workflow.

How It Works / Workflow

The system follows a simple end-to-end process:

Collect → Process → Calculate → Generate → Monitor
01

Collect

Google Forms are used to collect three types of operational data — employee registration, attendance records, and overtime records. Submitted data is automatically transferred into the spreadsheet system.

02

Process

Google Sheets organizes the submitted information into structured datasets. Raw data is separated from processed data so the original submissions stay protected while processed data is used for calculations and reporting.

03

Calculate

Spreadsheet formulas process the HR data automatically, including:

  • Attendance & late arrivals
  • Overtime
  • Basic salary, allowances & bonuses
  • Deductions & payroll totals
04

Generate

The processed data is used to automatically generate useful HR outputs — payroll records, payslips, employee ID cards, and HR dashboard data.

05

Monitor

Processed HR information is presented through a centralized dashboard and structured employee and payroll records, making it easier to monitor and manage.

Key Features

Centralized employee records that organize employee information in one structured system.

Attendance & Overtime

Digital attendance and overtime recording with automated processing and calculations.

Payroll Automation

Calculates salary components, overtime, allowances, bonuses, and deductions based on the available HR data.

HR Dashboard

Provides a centralized view of HR information for easier monitoring and reporting.

Automated Payslip

Generates payslip documents using processed employee and payroll data.

Automated ID Card

Generates employee ID cards from employee information stored in the system.

Automation Logic

The system uses a structured data flow:

Raw Data → Processed Data → Business Logic → Output

Raw data is kept separate from processed data before calculations and business rules are applied. This structure helps maintain data consistency, reduces repetitive manual processing, and makes the workflow easier to maintain and extend. The modular approach also allows the system to be expanded with potential features such as leave requests, reimbursement, or employee performance tracking.
